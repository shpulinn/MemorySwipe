# Исправление мигания при свайпе влево/вправо

## Диагноз

Корень проблемы — разная асинхронность в `removePhoto` vs `skipPhoto`:

- **`skipPhoto`** (свайп вверх): обновляет `state` **синхронно** — родитель перестраивается в том же кадре
- **`removePhoto`** (свайп влево/вправо): содержит `await _markAsViewed(photoId)` — обновление `state` откладывается до завершения async-операции

### Последовательность кадров при свайпе влево/вправо:

```
Кадр N:
  1. Анимация завершается → _onFlyComplete()
  2. setState → _isAnimating=false, _dragOffset=Offset.zero
  3. onSwiped() → removePhoto() → await _markAsViewed() → ПАУЗА
  4. Flutter перестраивает грязные виджеты:
     - Родитель НЕ обновлён (await ещё не вернулся)
     - SwipeableCardStack перестраивается: _dragOffset=Offset.zero → карточка в ЦЕНТРЕ
     - widget.photos[0] — СТАРОЕ фото (список ещё не обновлён)
     → ВИДНА СТАРАЯ КАРТОЧКА В ЦЕНТРЕ = МИГАНИЕ

Кадр N+1:
  5. _markAsViewed() завершается → state обновляется
  6. Родитель перестраивается → widget.photos[0] = новое фото
```

### Почему свайп вверх работает:
`skipPhoto` обновляет `state` синхронно → родитель обновляется в том же кадре → `widget.photos[0]` уже новое фото когда `SwipeableCardStack` перестраивается.

## Решение

Перенести сброс позиции карточки в `addPostFrameCallback`, чтобы он выполнился ПОСЛЕ обновления данных родителя.

### Файл: `lib/features/photo_swipe/presentation/widgets/swipeable_card_stack.dart`

Заменить `_onFlyComplete`:

```dart
void _onFlyComplete() {
    if (!mounted) return;

    final photo = widget.photos.first;
    final direction = _lastDirection!;

    // Сначала уведомляем родителя — он обновит список фото
    widget.onSwiped(photo, direction);

    // Сбрасываем позицию ПОСЛЕ кадра, когда родитель уже обновил данные
    WidgetsBinding.instance.addPostFrameCallback((_) {
      if (mounted) {
        setState(() {
          _isAnimating = false;
          _lastDirection = null;
          _dragOffset = Offset.zero;
          _rotation = 0;
        });

        if (widget.photos.length <= 5) {
          widget.onLoadMore?.call();
        }
      }
    });
}
```

### Почему это работает:

1. `onSwiped` вызывается СРАЗУ → родитель начинает обновление
2. `addPostFrameCallback` ставится в очередь
3. Если `removePhoto` (async): callback выполнится в следующем кадре, когда `_markAsViewed` уже завершился и `widget.photos` обновлён
4. Если `skipPhoto` (sync): `state` обновлён в этом же кадре, callback выполнится после — `widget.photos` уже обновлён

В обоих случаях к моменту сброса `_dragOffset` данные уже актуальны.

### Что НЕ менять:
- Виджет `Visibility` не возвращать (не нужен — карточка уже за экраном благодаря анимации)
- `_flyController.reset()` не вызывать (не нужен)

## Верификация:
1. Свайп влево — карточка улетает, вторая появляется без мигания
2. Свайп вправо — аналогично
3. Свайп вверх — аналогично (не сломать!)
4. Кнопки действий — работают
5. Быстрые повторные свайпы — все работают
6. Undo — возвращает карточку
